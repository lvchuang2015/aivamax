# SOP-AIVAMAX-Global-Daily-Execution-Rhythm

## Purpose

Provide a repeatable daily rhythm for AIvaMax social media growth projects.

## Public Course Layer

| Time block | Public-safe focus | Review point |
| --- | --- | --- |
| 08:00-10:00 | Observe platform signals and account health | Check abnormal login or content issues |
| 10:00-12:00 | Publish reviewed brand/product content | Confirm CTA and landing path |
| 12:00-14:00 | Respond to comments with value | Remove repetitive or low-context replies |
| 14:00-16:00 | Research target topics and communities | Save evidence before outreach |
| 16:00-18:00 | Publish visual/video content | Check captions, claims, and links |
| 18:00-20:00 | Review qualified interactions | Human review before direct follow-up |
| 20:00-21:00 | Log data and pause unsafe tasks | Record stop conditions |

## Internal Execution Layer

All repeatable automation tasks must include daily limits, pause conditions, account grouping, and human review ownership.
