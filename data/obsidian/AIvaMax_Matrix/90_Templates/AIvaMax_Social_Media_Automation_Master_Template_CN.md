# 一、模板总目标

本模板用于生成一套可以被 AI 复用的社媒营销自动化方案框架。它不是单个项目方案，而是一个可输入不同产品、行业、国家、周期、预算和营销目标后，自动生成具体执行计划的母模板。

核心目标：帮助用户通过 Facebook、Instagram、Twitter/X、Reddit、TikTok、Pinterest、YouTube 等社媒平台，完成获客、产品推广、品牌建立、内容种草、SEO 占位、活动推广、代理招商和长期增长。

| 需求类型 | 目标说明 | 典型结果 |
| --- | --- | --- |
| 获客型营销 | 找到潜在客户、建立联系、引导咨询 | 私信线索、评论线索、官网访问、表单提交 |
| 产品推广 | 长期曝光产品功能、使用场景、案例、优惠 | 产品认知提升、流量增长、试用注册 |
| 品牌建立 | 建立品牌专业形象、可信度、行业影响力 | 粉丝增长、搜索可见度、内容资产沉淀 |
| 内容种草 | 用多个内容触点影响用户认知 | 收藏、转发、评论、搜索品牌 |
| 社群渗透 | 进入行业相关群组、话题、Subreddit、评论区 | 社群讨论、自然互动、品牌提及 |
| 活动推广 | 推广限时优惠、发布会、试用活动、节日营销 | 短期流量、活动报名、转化提升 |
| SEO / 搜索占位 | 用社媒内容占据品牌词、产品词、行业词搜索结果 | Google / 平台内搜索曝光提升 |
| 口碑建设 | 通过教程、案例、问答、评价内容建立信任 | 正面口碑、用户证明、转介绍 |
| KOL / 合作拓展 | 寻找达人、博主、社群主、频道主合作 | 合作名单、邀约回复、联名内容 |
| 再营销辅助 | 对已有访客、粉丝、互动用户进行二次触达 | 私信跟进、评论召回、优惠提醒 |
| 新品冷启动 | 新品牌 / 新产品从 0 到 1 建立初始曝光 | 首批内容、首批粉丝、首批互动 |
| 多地区推广 | 针对不同国家 / 语言 / 城市建立区域化传播 | 本地化账号矩阵、本地内容、本地线索 |
| 竞品流量截取 | 围绕竞品话题、竞品评论区、竞品粉丝进行内容和互动 | 竞品用户触达、替代方案认知 |
| 行业教育 | 对复杂产品进行持续教育和认知培养 | 长期信任、专业权威、内容沉淀 |
| 招商 / 代理招募 | 招募渠道商、代理商、加盟商、合作伙伴 | 代理咨询、合作申请、商务私信 |

不同平台承担不同营销角色，不应该所有平台发一样的内容。AI 生成方案时，应根据行业、目标客户和推广周期自动调整平台权重。

| 平台 | 核心作用 | 适合内容 | 适合目标 |
| --- | --- | --- | --- |
| Facebook | 群组、主页、私域互动、B2B/B2C 获客 | 长文、图片、群组帖、评论、Messenger | 获客、社群、活动、代理招商 |
| Instagram | 视觉种草、品牌形象、生活方式展示 | Reels、图片、Carousel、Story | 品牌、种草、电商 |
| Twitter/X | 话题传播、观点输出、行业讨论 | 短帖、Thread、评论、转发 | B2B、SaaS、Web3、科技 |
| Reddit | 深度讨论、真实需求发现、垂直社区渗透 | 问答、经验贴、讨论贴 | 产品验证、口碑、技术类产品 |
| TikTok | 快速曝光、短视频种草、趋势传播 | 短视频、挑战、教程、故事化内容 | 爆发式曝光、电商、App |
| Pinterest | 长周期搜索流量、视觉 SEO | Pin、信息图、教程图、产品图 | 电商、家居、美妆、设计、教程 |
| YouTube | 权威内容、搜索流量、长期信任 | Shorts、教程、评测、案例、直播回放 | 品牌、教育、产品转化 |

# 五、AIvaMax 任务类型库模板

下面任务库用于生成具体 AIvaMax 执行计划。AI 应根据目标和周期自动选择任务类型、账号组、执行频次和时间段。

### 5.1 内容发布类任务

| 任务类型 | 作用 | 可执行平台 | 适合目标 |
| --- | --- | --- | --- |
| 定时发帖 | 保持账号活跃和内容曝光 | 全平台 | 品牌、产品推广 |
| 批量发帖 | 多账号同步推广同一主题 | FB、IG、X、Pinterest、Reddit、YouTube、TikTok | 活动、产品曝光 |
| 多版本 Spintax 发帖 | 避免内容完全重复，提高内容多样性 | 多平台 | 大规模内容矩阵 |
| AI 生成文案发布 | 根据主题自动生成不同风格内容 | 多平台 | 内容生产 |
| 视频发布 | 发布 Shorts / Reels / TikTok / YouTube 视频 | IG、TikTok、YouTube、FB | 种草、曝光 |
| 图片 / Pin 发布 | 图文种草和视觉搜索 | IG、Pinterest、FB | 电商、设计、生活类 |

| 活动内容发布 | 推广优惠、限时活动 | 全平台 | 短期转化 |

### 5.2 互动增长类任务

| 任务类型 | 作用 | 说明 |
| --- | --- | --- |

| 收藏 / 保存 | 增强内容权重和账号行为多样性 | 适合 Instagram、TikTok、Pinterest |
| 观看视频 | 建立账号正常兴趣画像 | 适合 TikTok、YouTube、Reels |
| 回复评论 | 激活已有互动，提高转化 | 适合品牌账号和客服账号 |
| 群组互动 | 在群组中回答问题和参与讨论 | 适合 Facebook、Reddit |
| 话题互动 | 围绕关键词参与实时讨论 | 适合 X、Reddit、TikTok |

### 5.3 搜索与发现类任务

| 任务类型 | 作用 |

| 趋势关键词监控 | 捕捉热点内容机会 |

### 5.4 私信 / 线索培育类任务

| 任务类型 | 作用 | 使用原则 |
| --- | --- | --- |

### 5.5 监控与优化类任务

| 任务类型 | 作用 |

# 六、营销目标到账号与任务组合模板

## 6.1 获客型方案

适合：B2B SaaS、软件工具、代理招商、本地服务、高客单产品。

### 账号组合

| 账号类型 | 权重 |
| --- | --- |
| 品牌主账号 | 20% |
| 专家 / 创始人账号 | 15% |
| 社群互动账号 | 30% |
| 内容种草账号 | 20% |
| 客服 / 咨询账号 | 10% |
| 案例证明账号 | 5% |

### 任务组合

| 任务 | 权重 |
| --- | --- |
| 关键词搜索用户 / 帖子 | 20% |
| 评论互动 | 25% |
| 内容发布 | 20% |
| 私信跟进 | 15% |
| 群组 / 社区互动 | 15% |
| 案例内容发布 | 5% |

### 内容重点

- 痛点型内容：你是否正在遇到 XXX 问题？

- 解决方案型内容：如何用 XXX 方法解决 XXX？

- 对比型内容：传统方法 vs 自动化方法

- 案例型内容：某客户如何在 30 天内提升 XXX

- 轻 CTA：需要模板可以私信 / 评论 keyword / 访问官网

## 6.2 产品推广型方案

### 账号组合

| --- | --- |
| 品牌主账号 | 25% |
| 产品功能账号 | 25% |
| 内容种草账号 | 25% |

# 十八、评论模板库

### 18.1 痛点型评论

> 这个问题其实很多团队都会遇到，尤其是当账号数量、内容频率和互动量上来之后，纯手动管理会非常吃力。比较好的方式是先把内容、账号和任务分组，再用自动化工具做基础执行，人工只负责策略和关键回复。

### 18.2 经验分享型评论

> 我们之前测试过类似场景，效果比较稳定的做法不是一开始大量发布，而是先用 7-14 天测试内容角度，找到回复率最高的主题，再逐步放大账号和任务量。

### 18.3 产品引导型评论

> 如果你的目标是多平台持续发布、互动和获客，可以考虑用一套统一的自动化流程来管理。核心不是单纯发帖，而是“内容 + 搜索 + 互动 + 跟进 + 数据复盘”的闭环。

### 18.4 轻 CTA 评论

> 我整理过一套类似的执行清单，如果你需要，我可以分享一个简化版给你参考。

# 二十、最终可复用项目生成规则

当以后使用这个模板生成具体项目方案时，AI 必须遵守以下规则：

1. 先判断项目目标：获客、品牌、产品推广、活动、SEO、招商。

1. 再判断行业：SaaS、电商、本地服务、AI、金融、教育、工具、代理等。

1. 再判断周期：7 天、14 天、30 天、60 天、90 天。

1. 再选择平台权重。

1. 再设计账号矩阵。

1. 再设计内容主题。

1. 再拆 AIvaMax Campaign。

1. 再拆每日任务。

1. 再写评论、私信、发帖模板。

1. 再设计线索转化路径。

1. 再给出效果预估。

1. 最后给出复盘和优化规则。

# 二十一、最重要的执行原则

这套模板的核心不是“批量发垃圾内容”，而是用账号矩阵和自动化系统承接重复执行，用内容质量、互动上下文和数据复盘决定增长效率。

> 账号矩阵化内容差异化任务阶段化互动上下文化线索流程化数据复盘化执行自动化关键节点人工审核

> 执行边界：AIvaMax 适合承担高频、重复、可标准化的执行部分，例如多账号管理、自动发帖、排程、点赞、评论、关注、搜索、私信、AI 内容、任务监控和数据记录；策略、品牌定位、敏感回复、成交沟通、客户筛选，仍应由人工或人工审核后的 AI 流程控制。

> 产品信息+ 用户痛点+ 推广目标+ 推广周期+ 平台权重+ 账号矩阵+ 内容主题池+ AIvaMax 任务库+ 每日执行计划+ 私信 / 评论 / 发帖模板+ 数据统计+ 阶段复盘= 可自动化执行的完整社媒营销方案
