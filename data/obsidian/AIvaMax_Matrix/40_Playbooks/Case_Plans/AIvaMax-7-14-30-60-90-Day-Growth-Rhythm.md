# AIvaMax 7/14/30/60/90 Day Growth Rhythm

## Purpose

This playbook converts a growth project into staged operating cycles. It should be used by course module 06, client delivery templates, and project review notes.

## Rhythm Map

| Cycle | Primary job | Main output | Review gate |
| --- | --- | --- | --- |
| 7 days | Diagnose and prepare | Intake, account audit, platform priority, first calendar | Risk boundary approved |
| 14 days | Test positioning | Small content set, early engagement review, lead signal notes | Keep/adjust platform weights |
| 30 days | Build repeatable rhythm | Weekly content system, engagement workflow, data review | Decide whether to scale |
| 60 days | Expand working channels | Channel-specific playbooks, stronger segmentation, improved assets | Remove weak tasks |
| 90 days | Productize the system | Client-ready SOP, review dashboard, next-quarter roadmap | Package for reuse |

## Cycle Rules

1. Do not scale a task before the previous cycle has a review note.
2. Separate content performance from lead quality; both are needed for a growth decision.
3. Keep a single owner for each cycle review.
4. Move high-risk conversation or outreach details into internal SOP only.

## Output Checklist

- Project input schema completed.
- Account matrix drafted and reviewed.
- Platform weight table completed.
- Content calendar created.
- Task library items selected.
- Risk review completed for message and comment flows.
- Forecast model updated at the end of each cycle.
