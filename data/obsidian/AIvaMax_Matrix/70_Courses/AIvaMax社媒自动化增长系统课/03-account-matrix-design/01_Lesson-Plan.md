# Lesson Plan - Module 03: Account Matrix Design

## Teaching Goal

Teach students to design account roles instead of using identical accounts for identical actions.

## Lesson Flow

| Segment | Teaching point | Instructor action |
| --- | --- | --- |
| 0-5 min | Account matrix means role design | Explain brand, expert, product, community, support, proof roles |
| 5-15 min | Match roles to content jobs | Map each role to content type and audience stage |
| 15-25 min | Choose lightweight, standard, or extended matrix | Use project size and duration as the decision rule |
| 25-35 min | Define ownership and review | Add owner and review column to the matrix |
| 35-45 min | Turn the matrix into weekly workload | Convert roles into content and review tasks |

## Instructor Demo

Use one realistic project brief and show how this module changes the operating decision. Keep the demo focused on method, worksheet completion, and review gates.

## Public/Private Boundary

Public teaching may include frameworks, worksheets, examples, and review logic. Internal execution details stay in SOPs until they pass risk review.
