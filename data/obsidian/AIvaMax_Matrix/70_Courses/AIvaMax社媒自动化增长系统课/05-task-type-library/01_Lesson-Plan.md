# Lesson Plan - Module 05: Task Type Library

## Teaching Goal

Teach students to select task families by goal and risk level rather than treating all actions as equal.

## Lesson Flow

| Segment | Teaching point | Instructor action |
| --- | --- | --- |
| 0-5 min | Task library is a menu, not a mandate | Split tasks into publish, discover, engage, follow-up, monitor |
| 5-15 min | Match tasks to marketing goals | Build a goal-to-task matrix |
| 15-25 min | Add stage logic | Show how cold start, growth, conversion, and review stages differ |
| 25-35 min | Add risk labeling | Mark high-risk communication tasks |
| 35-45 min | Choose a small task set for one project | Limit the plan to what can be reviewed |

## Instructor Demo

Use one realistic project brief and show how this module changes the operating decision. Keep the demo focused on method, worksheet completion, and review gates.

## Public/Private Boundary

Public teaching may include frameworks, worksheets, examples, and review logic. Internal execution details stay in SOPs until they pass risk review.
