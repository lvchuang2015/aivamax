# JarveePro Vendor Source Docs

This folder stores source documents provided by JarveePro or JarveePro-adjacent partners.

These files are source-corpus material, not public AIvaMax assets. Use them as evidence and operating references first, then create adapted AIvaMax templates, SOPs, playbooks, and course modules in `AIvaMax_Matrix`.

## Usage Rule

1. Preserve the original document as JarveePro source material.
2. Convert a Markdown copy for Obsidian search and local review.
3. Create public-facing AIvaMax derivatives only after brand migration, wording cleanup, compliance review, and course-structure adaptation.
