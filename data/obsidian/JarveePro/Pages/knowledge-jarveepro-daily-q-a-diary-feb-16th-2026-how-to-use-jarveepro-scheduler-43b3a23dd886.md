JarveePro Daily Q&A Diary – Feb 16th, 2026 How to Use JarveePro Scheduler & Manage Scheduled Campaigns

2026-02-16

Introduction

Many users schedule campaigns inside JarveePro but get confused when:

The dashboard shows “Scheduled (In 60m)”

It displays “Over 60m”

The Scheduler Manager shows “Valid”

The default timing does not match exact minute expectations

This Daily Q&A clarifies how JarveePro Scheduler works, how to check scheduled campaigns properly, and how to manage them without confusion.

Q1: How do I use JarveePro Scheduler correctly?

Answer:

To schedule a campaign:

Go to

Campaigns

Select the campaign you want to schedule

Click

Add Schedule

Choose:

Schedule Type (commonly Run Once)

Set Start Time

Enable Schedule

Click OK

After saving:

The schedule will appear inside

Scheduler Manager

Status should show

Valid

The campaign dashboard will display a countdown

Important:

The system works on a

default 40-minute interval cycle

, meaning execution timing follows scheduler processing windows — not second-by-second precision.

If status shows

, your schedule is correctly configured.

Q2: How do I check and manage scheduled campaigns?

Answer:

There are two places to monitor scheduled campaigns:

1 Scheduler Manager

Open

JarveePro Scheduler

to see:

Platform

Campaign Type

Schedule Type

Start Time

Status (Valid / Invalid)

If it shows

Valid

, the schedule is active.

You can:

Edit schedule

Delete schedule

Verify timing

Adjust configuration

2 Campaign Dashboard

On the Campaign Dashboard, you may see:

Scheduled (In 60m)

→ Campaign will run in approximately 60 minutes

Scheduled (Over 60m)

→ The campaign will run

in more than 60 minutes

This is normal behavior due to the scheduler’s 40-minute processing interval.

It does not mean the campaign failed.

Q3: What does “Over 60m” mean in the Campaign Dashboard?

Answer:

“Over 60m” means:

The campaign will run

It does

not

mean there is an error.

Because the Scheduler runs in processing cycles , the dashboard shows time in ranges instead of exact minute-by-minute countdowns.

So:

In 60m

→ Campaign will run within the next 60 minutes

Over 60m

→ Campaign is scheduled, but execution is more than 60 minutes away

As long as the status in

Scheduler Manager shows “Valid”

, everything is working correctly.

No action is required.

Q4: What should I check if my schedule does not execute?

Answer:

Verify:

Schedule status is

Valid

Enable Schedule is checked

Campaign itself is enabled

VPS Mode is active (if required)

System time is correct
