Inquiry 2: TikTok Comment Automation Setup

I need, for example, to place 150–200 TikTok accounts there and have them write comments on posts using text that I choose — but not all accounts should comment on one post. I want to control how many (like 1–3) accounts comment per post. How can I organize this using your software, and how much will it cost me per month for 150 accounts to write 20 comments per day?

This can be achieved using JarveePro’s

automation scheduler

and

spintax comment system

Import your 150–200 TikTok accounts into a managed group.

Use the

spintax format

to generate unique comment variations.

Set posting limits (e.g., 1–3 comments per post) within task settings.

Schedule each account to post up to

20 comments daily

, with random intervals to simulate natural activity.

Inquiry 5: Running Multiple Screens Without VPS

User (Ahmed Bavugari):

Hello, how can I use multiple screens without buying a VPS? I want it to perform on my PC.

Support:

Yes, it’s possible to manage multiple screens locally if your system has strong hardware performance (

CPU ≥ i7, 32GB RAM recommended

).

Ensure each account uses

a unique proxy or dedicated residential IP

to avoid session overlaps or account flags.
