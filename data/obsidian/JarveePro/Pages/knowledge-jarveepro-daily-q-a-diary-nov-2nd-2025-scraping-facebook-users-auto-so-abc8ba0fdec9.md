Questions & Answers

Q1: How can I scrape a database of Facebook users?

Answer:

To extract Facebook user data, use

JarveePro’s Content Explorer

. It allows you to collect leads such as group members, page followers, and profile lists — all without coding.

Steps:

Open

Content Explorer

inside JarveePro.

Select

Facebook

as your target platform.

Choose the data type (Users, Groups, or Pages).

Enter your keywords or target URLs.

Start scraping and check your

Results

tab for outputs.

Note:

There’s a short YouTube demo for a quick walkthrough.

Q2: Why can’t JarveePro bypass Captcha and it closes automatically?

Answer:

If the

2Captcha window closes automatically

, the most common reasons are API key misconfigurations or unstable proxy connections.

Try this checklist:

Confirm your Yes

Captcha API Key

is valid and active.

Ensure proxies are working correctly.

Extra Insight:

JarveePro doesn’t control 2Captcha servers — it communicates via API. If you face repeated closure issues, verify your API balance and key status directly from your 2Captcha dashboard.

Q3: How can I run multiple threads at once in a campaign?

Running multiple threads allows simultaneous posting, scraping, or engagement across accounts.

How to enable multiple threads:

Go to

Campaign Settings

Find the

Thread Control

or

Performance Settings

section.

Increase the

Maximum Threads

(e.g., from 1 to 5 or 10).

Save and restart the campaign.
