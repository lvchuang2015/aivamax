Search Tools

2025-05-13

Search Tools: A

utomatically find target content or users

across social media platforms.

It helps you collect data that can be used for engagement actions like following, liking, commenting, or messaging.

Accounts

: Manage your connected social media accounts.

Search Tools:

Automatically search for users, posts, or hashtags.

Generation:

Used to create, configure, view, and run search and scraping tasks.

Name

: Task name, For example: "YT Search 1", "YT Search 2".

TaskType

: Displayed as "Only Collect", indicating that this task only performs data collection.

CollectType

: Shown as "Search Videos", meaning the task collects video search results.

UpdateTime

: The last time the task was edited or saved.

Status

: Current status of the task.

Message

: Displays log information when the task runs.

Operate

: Includes three buttons:

Edit Task

View Logs

Delete Task
