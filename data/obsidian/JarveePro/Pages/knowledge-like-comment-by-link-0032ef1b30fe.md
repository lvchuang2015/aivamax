Like Comment by Link

2025-05-18

Step 1: Choose "Campaigns" and Facebook, and select posting task.

Step 2: Select accounts and add comment link source that you want to like. You can import multiple links in CSV format or add them one by one.

Step 3: Complete task settings and click "OK" to start.

What This Page Does:

This tab is to configure how many Facebook comments are liked by link, how many likes each comment will receive, and how the data is used.

If you Want Each Comment to Get 500 Likes, what will you do?

Set “Number of Liked Per Comment”: From 500 to 500

Set “Number of Liked Comments Per Account”: From 1 to 1

→ Each account will like only one comment

In Select Accounts: Choose 500 Facebook accounts

In Post's Comment Link Source tab: Import 500 comment links

In Task Settings:

Keep “Number of Liked Per Comment”: 500–500

Keep “Number of Liked Comments Per Account”: 1–1

(Optional) Check "Random Use of Data" if you want to randomize which comments are liked first

Set Like Type: Choose from available Facebook reactions (e.g., Like, Love)

If you Want One Account to Like 500 Comments, what will you do?

Keep “Number of Liked Comments Per Account” selected

Set it: From 500 to 500

Set “Number of Liked Per Comment”: From 1 to 1

→ Each comment receives only one like

In Select Accounts: Use just one Facebook account

In Post's Comment Link Source tab: Import 500 different comment links

Make Sure:

The number of Facebook accounts or comment links matches your goal

You configure the "Like Type" (e.g., Like, Love, etc.) according to your campaign tone

(Optional) Set "Accounts Use Interval(s)": For example, 1–1 means no delay between accounts

Real-World Example Setup for New Users:

Scenario: You want to like 500 different Facebook comments using 500 different accounts

In Select Accounts: Select 500 Facebook accounts

In Post's Comment Link Source tab: Import 500 comment links (1 per account)

In Task Settings:

Number of Liked Comments Per Account: 1 to 1

Number of Liked Per Comment: 500 to 500

(Optional) Enable Random Use of Data

Select your Like Type

Leave "Data is not reused" unchecked (unless you want unique targets)
