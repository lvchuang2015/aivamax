Q1: Can JarveePro run campaigns every day and continue where it left off?

Answer:

Yes. JarveePro supports continuous automation using the

Loop Run scheduling mode

In the Campaign Schedule settings, you can configure automation like this:

Schedule Type:

Loop Run

Restart campaign from the beginning:

Enabled

Stop After:

0 times (unlimited loop)

Interval in Hours:

Set based on your campaign needs (example: 1 hour)

Enable Schedule:

Checked

With these settings:

The campaign runs continuously

It repeats automatically

It restarts when the loop completes

This setup allows campaigns to run

daily without manual restarting

, making it ideal for long-term automation workflows.

Q2: How can I verify that my automation schedule is active?

Answer:

Status =

Valid (Active)

If the status shows

Valid

, it means:

The schedule configuration is

correct

The campaign

exists and is recognized

The task is

ready to run at the scheduled time

If these indicators are updating, the automation is working properly.

Q3: Does JarveePro support Instagram Story auto-liking?

Answer:

Yes. Instagram

Story Auto-Liking is available in JarveePro

, and it is even included in the

free version

This feature allows users to:

Automatically like Instagram Stories

Increase profile visibility through lightweight engagement

Interact with targeted audiences

Story engagement is often used as a

low-risk growth strategy

, especially when warming up accounts.

Q4: Can JarveePro search or scrape Instagram Stories and Reels?

Answer:

Yes. Using the

Advanced Content Explorer

, JarveePro supports several search options including:

Search Posts by Keywords

Search Comments by Post Link

Search Reels by Users

Search Story by Users

Search Users by Keywords

The options

and

allow you to monitor and collect content from

specific Instagram accounts

For example, you can:

Track stories from competitors

Monitor influencers

Analyze niche creators

Gather engagement targets

This makes the tool very useful for

content monitoring and audience research

Q5: Can JarveePro filter search results or scraped data?

Answer:

Yes. The

Filter Options

in Advanced Content Explorer allow users to refine results based on various criteria.

Examples include:

Engagement levels

Time

Account characteristics

Filtering helps marketers focus on

higher-quality or more relevant accounts

, improving campaign performance.

Q6: Does JarveePro support Auto Comments and Auto Direct Messages?

Yes. JarveePro includes powerful automation modules such as:

Auto Comment

Auto Direct Message

Auto Follow

Auto Like

Story Engagement

These modules can be combined with scraped users or keyword searches to create targeted campaigns.

Users can also configure:

Daily limits

Random delays

Message rotation

Target filters

This flexibility allows JarveePro to automate large-scale engagement safely.
