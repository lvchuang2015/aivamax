How to Assign and Configure Proxies in JarveePro Account Manager (Complete Guide)

2026-02-25

Overview

The Account Manager and Proxy Manager in JarveePro allow you to assign individual proxies to each social media account. Proper proxy configuration is essential for account safety, platform compliance, and scalable automation.

JarveePro provides two methods to assign proxies:

Assign proxy directly inside Account Manager

Assign and manage proxies centrally using Proxy Manager

Both methods ensure accounts operate through dedicated IP addresses.

Why Proxies Are Required

Using proxies provides several important benefits:

Prevents multiple accounts from sharing the same IP address

Reduces the risk of account restrictions or detection

Enables safe scaling across multiple accounts

Allows geo-targeting using location-specific proxies

Improves account stability and trust score

Best practice: Assign one proxy per account.

Supported Proxy Types

JarveePro supports:

HTTP

HTTPS

SOCKS4

SOCKS5 (Recommended)

SOCKS5 is strongly recommended for residential and mobile proxies due to better compatibility and stability.

Method 1: Assign Proxy via Account Manager

This method is ideal when adding or configuring individual accounts.

Step 1: Open Account Manager

Go to JarveePro Dashboard

Click

Account Manager

Select the platform (Instagram, Facebook, Twitter, TikTok, etc.)

Step 2: Edit Account

Select the account

Click the

Edit (pencil icon)

Locate the

Proxy Settings

section

Step 3: Enter Proxy Details

Enter the following:

Proxy Type: HTTP

Host: Proxy IP address

Port: Proxy port

Username: Proxy username

Password: Proxy password

Example:

Host: 193.228.193.86

Port: 12321

Username: your_username

Password: your_password

Step 4: Save and Verify

Click OK

JarveePro will verify the proxy automatically

Ensure proxy shows in the Proxy Column

The account will now operate through the assigned proxy.

Method 2: Assign and Manage Proxies via Proxy Manager (Recommended)

This method provides centralized proxy management and is recommended for managing multiple accounts.

Step 1: Open Proxy Manager

Go to JarveePro Dashboard

Click

Proxy Manager

Select or create a category

You will see a list of all imported proxies.

Step 2: Check Proxy Usage

Proxy Manager shows:

Proxy availability status

Number of accounts bound to each proxy

Platform assignment

Proxy connection status

This helps prevent assigning the same proxy to multiple accounts unintentionally.

Step 3: Bind Proxy to Account

To assign a proxy:

Locate the proxy

Select or assign the account(s) to bind

Click

Save

The proxy will now be assigned to the selected account.

Step 4: Verify Proxy Binding

Confirm the following:

Proxy status shows

Available

Proxy shows correct number of bound accounts

Account is successfully connected using the proxy

Bulk Proxy Import Format

JarveePro supports bulk proxy import using this format:

IP:PORT:USERNAME:PASSWORD

Example:

193.228.193.86:12321:user:password

Best Practices

Follow these recommendations for optimal performance:

Use one proxy per account

Avoid sharing proxies between accounts on the same platform.

Use SOCKS5 residential or mobile proxies

These provide higher trust and better performance.

Match proxy location to account location

Improves account stability and reduces verification triggers.

Use Proxy Manager for bulk management

Provides full visibility and centralized control.

Always verify proxy connectivity before use

Ensures proper configuration.

Common Issues and Solutions

Issue: Proxy shows unavailable

Solution:

Verify proxy credentials

Ensure proxy is active with provider

Select correct proxy type (SOCKS5 recommended)

Issue: Multiple accounts using same proxy

Open Proxy Manager

Check proxy binding count

Assign dedicated proxies per account

Issue: Account connection problems

Reassign proxy

Verify proxy availability

Restart JarveePro if needed

Summary

JarveePro allows proxy assignment through both Account Manager and Proxy Manager. Account Manager is ideal for individual account setup, while Proxy Manager provides centralized proxy control, usage visibility, and bulk assignment capabilities.

Using SOCKS5 residential or mobile proxies, assigning one proxy per account, and verifying proxy connectivity ensures safe, stable, and scalable automation.

Proper proxy management is essential for maintaining long-term account health and automation reliability.
