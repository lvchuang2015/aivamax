Send Message

2025-06-14

Step 1: Choose "Campaigns" and TikTok, and select task.

Step 2: Select account(s) and add user Url(s). You can import multiple user Url you want to send in CVS format. Or add one by one.

Step 3: Import multiple messages you want to send in CVS format. Or add one by one.

Step 4:

What This Page Does:

This tab is to configure how many messages are sent to per TikToK user, from per account, and in what order.

If you Want to Send the Same Message to 500 Users, what will you do?

Select “Number of Messages Per Account”

If you're a individual version, you have no choice but only one

TikToK

account.

Keep “Number of Messages Per User” selected.

Set it: From 500 to 500 (Not Recommended, Solution: Upgrade to Enterprise Version or Full Version to Manage More Accounts)

If you're a full version user,

Set it: From 1 to 1 (or more if needed).

Uncheck “Data is not reused”

Use a single message in the "Messages" tab or a few spintax options.

If you Want to Send Unique Messages to 500 Users, what will you do?

Keep the “500 to 500” range.

Make sure:

You have 500 message entries.

You have 500

TikToK

usernames or URLs.

Keep “Data is not reused” checked to remove duplicate DMs.

Real-World Example Setup for New Users:

Scenario: Send the same message to 500 users with 500 different accounts

In Select Accounts: Select 500

accounts

In Messages tab: Write one message or a spintax version.

In User URL tab: Import 500

usernames.

In Task Settings:

Use “Number of Message(s) Per Account”: From 1 to 1 to ensure each account will only send out 1 message.

Keep “Number of Messages Per User” selected. Set it: From 1 to 1 to ensure each TikTok profile will only receive one message.

Uncheck “Data is not reused”cause you're sending the exact same message to different users.
