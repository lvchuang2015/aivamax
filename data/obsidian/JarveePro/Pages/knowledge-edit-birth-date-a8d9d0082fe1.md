## Content

Edit Birth Date

2025-06-01

Step 1: Choose "Campaigns" and Twitter, and select task.

Step 2: Select account(s) and add birth date(s). You can import multiple birth dates in CVS format. Or add one by one.

Step 3: This task settings are all optional settings. Whether you want to click it, it depends on your needs. But you must

click "OK" to start.

Data is not reused

: Prevents using the same data across multiple tasks.

Random use of data

: Uses data in order (unchecked) or randomly (checked).
