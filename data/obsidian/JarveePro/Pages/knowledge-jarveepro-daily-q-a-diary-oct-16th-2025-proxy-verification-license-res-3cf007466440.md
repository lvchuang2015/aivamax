Proxy Usage Question

User Question:

“If I buy 1 proxy, can I use it on 3 Instagram, 3 Facebook, and 3 TikTok accounts?”

Response:

While technically possible,

sharing one proxy across multiple platforms

increases the risk of linked activity and account restriction. For best results:

Use

1 dedicated proxy per account

Tip:

JarveePro’s Smart Proxy Management system can help you automatically assign proxies per account group and check proxy availability.

VPS Version and Setup

User Follow-Up:

“This version doesn’t allow connecting to VPS, right? I have two laptops I can use as VPS — does the Full version allow that?”

Response:

Correct —

VPS functionality

is available in the

JarveePro VPS version

only.

Your

local PC license

runs under a local IP environment, while the

VPS Version

operates with public IPs suitable for 24/7 automation.

If you wish to scale your operation, you can purchase multiple licenses to run on different PCs or buy VPS version.
