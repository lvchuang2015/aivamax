Reply

2025-06-02

Step 1: Choose "Campaigns" and Twitter, and select task.

Step 2: Select account(s) and add tweet source(s). You can import multiple tweet source that you need to reply in CVS format or add one by one.

Step 3:Import multiple text contents when you reply tweets in CVS format or add one by one.

Step 4: Browse photo(es) or video(es) when you reply the tweets.

Step 5:

What This Page Does

This section lets you configure how many replies each tweet receives, or how many tweets each account will reply to. You can also define how data is used and whether it's reused across accounts.

If You Want One Tweet to Get 500 Replies

Select "Number of replies each tweet increases"

Set it: From 500 to 500

This means you need 500 accounts to send one reply each

Keep "Data is not reused" checked to avoid duplicate replies

Do not check "Random use of data" if you want replies to follow the input order

Ensure you have 500 reply texts ready in the "Text" tab

Make sure the tweet URL is added in the "Post URL" tab

If You Want Each Account to Reply to Different Tweets

Select "Number of tweets each account reply"

Set it: From 1 to 1

Uncheck "Data is not reused" to allow accounts to use tweet URLs or reply content more than once

Import tweet URLs in the "Post URL" tab

Enter reply content in the "Text" tab

Real-World Example

Goal: Use 500 Twitter accounts to reply once to the same tweet

In "Select Accounts": Choose 500 accounts

In "Post URL": Add the tweet URL you want to target

In "Text": Prepare 500 replies (or spintax variations)

In "Task Settings":

Select "Number of replies each tweet increases"

Set it: 500 to 500

Keep "Data is not reused" checked

Leave "Random use of data" unchecked
