Scraping Recent or Monitoring New Content & Followers in JarveePro Content Explorer

2026-01-29

Introduction

Keeping your social media accounts active and engaged is key to growing reach, visibility, and audience interaction. Manually tracking new posts, stories, Reels, or follower changes across multiple platforms is time-consuming and inefficient. JarveePro’s Content Explorer simplifies this process by allowing you to

scrape recent content, monitor new posts, and track new followers or followings automatically

. With this guide, you’ll learn a universal generate rule that works for

Instagram, Twitter, Facebook, YouTube

, and more — ensuring your accounts are always interacting with fresh and relevant content.

Step 1: Create a Search Task

Open

JarveePro Content Explorer

Click

Create Task

Enter

Task Name

(e.g.,

Monitor_NewContent_JarveeProAdmin

).

Select

Type

Search

→ Only track content or users.

Search + Generate

→ Track content/users and produce posts or actions from results.

Configure

Search Source

Platform:

Instagram, Twitter, Facebook, YouTube, or others

Search Type:

Content

→ Story, Reel, Post, Tweet, or Video by Users

Followers

→ Track new followers of a user/account

Followings

→ Track new accounts someone follows

Hashtag/Keyword

→ Recent posts containing specific tags or keywords

Run Accounts:

Select which account(s) will execute the tracking

Usernames/Keywords/Hashtags:

Enter your target users or tags

Step 2: Configure Monitoring Settings

Save all results:

✅ Ensure every tracked content, follower, or following is recorded.

Enable real-time monitoring:

Option 1: Search all new results

→ Capture all existing content/followers/followings, then continue monitoring future updates.

Option 2: Search for results published within X hours

→ Only capture recent posts/followers/followings to save resources.

Example:

Scrape the last 24 hours first, then continue tracking new results.

Monitoring interval (minutes):

Set a range (e.g., 10–15 minutes).

Active monitoring hours:

Define when the task should run (e.g., 00:00–23:59).

Tip:

Setup is identical across

content, followers, and followings

— select the appropriate

Search Type

for your goal.

Step 3: Use Monitored Results

Assign your

monitor task

as a source for campaigns, content generation, or automated engagement.

JarveePro will automatically find new posts or new followers/followings and execute the configured actions — no manual input required.

Benefits

Track

only fresh content and new users

efficiently.

Keep accounts

active and relevant

across multiple platforms.

Automate content creation, engagement, or follow actions based on real-time data.

Works for

Instagram, Twitter, Facebook, YouTube

, and more.

Summary

JarveePro Content Explorer allows you to

scrape recent content and monitor new followers/followings automatically

, keeping your accounts active, engaged, and optimized for growth. By setting up a universal monitoring task, you can track Instagram, Twitter, YouTube, Facebook, and more — saving time while ensuring your accounts interact with the most relevant posts and users. With this generate rule, maintaining a consistent social media presence has never been easier.
