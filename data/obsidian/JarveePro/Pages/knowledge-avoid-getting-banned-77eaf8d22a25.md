Avoid Getting Banned

2025-05-14

How to prevent Your account from being blocked:

1. Use the specific proxy and user agent to run your account each time.

2. Do not run many tasks at the same time with one account. For example, use account A to do the follow task and unfollow task at the same time.

3. If you want to run many tasks with one account, please set a specific running time for each task.

4. Do not follow so many people per time, just make your task like the real people are doing it. That means do not run your task too frequently.
