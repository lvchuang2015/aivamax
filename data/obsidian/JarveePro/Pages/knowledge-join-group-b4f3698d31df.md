Join Group

2025-05-19

Step 1: Choose "Campaigns" and Facebook, and select task.

Step 2: Select account(s) and add group URL source(s). You can import multiple group URL sources in CSV format or add them one by one.

Step 3: Select account(s) and add group URL source(s). You can import multiple group URL sources in CSV format or add them one by one.

Step 4: Complete task settings and click "OK" to start.

What This Page Does:

This tab is used to configure how many Facebook comments each post receives, and how many comments each account sends.

If You Want to Leave 500 Comments on One Post:

Select “Number of Comments Per Post”

Set it: From 500 to 500 — this means the selected post will receive exactly 500 comments from your chosen accounts.

✅ This setting is currently enabled.

Uncheck “Random Use of Data”

This ensures the accounts will comment on the posts in the order they are provided.

❌ Random mode is disabled.

Set “Account Use Interval(s)”

Set it: From 1 to 1 — this spaces each account’s action by 1 second for natural pacing.

✅ Interval is active.

If You Want Each Account to Comment on Different Posts:

Select “Number of Comments Per Account”

Set it: From 1 to 1 — this ensures each account only leaves one comment.

This guarantees consistent order based on your uploaded data list.

Use Account Intervals to control speed and avoid detection.

Real-World Example Setup for New Users:

Scenario: 500 Comments on One Post

In Select Accounts Tab: Choose 500 Facebook accounts

In Post Sources Tab: Add the post URL you want to promote

In Task Settings:

Select “Number of Comments Per Post”: From 500 to 500

Leave “Number of Comments Per Account” unchecked

Set Account Use Interval(s): From 1 to 1

Uncheck “Random Use of Data”

✅ This setup ensures the post receives 500 comments from different accounts, delivered in order and spaced by a short interval.
