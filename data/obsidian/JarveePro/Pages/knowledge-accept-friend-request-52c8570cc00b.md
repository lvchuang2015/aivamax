Accept Friend Request

2025-05-19

Step 1: Choose "Campaigns" and Facebook, and select task.

Step 2: Select account(s) and add user link or username. You can import multiple user links or usernames of friends request in CSV format or add them one by one.

Step 3:

You can import multiple user links or usernames to exclude friends in CSV format or add them one by one.

Step 4: Complete task settings and click "OK" to start.

What This Page Does

This "Task Settings" tab under the Accept Friend Request module allows you to configure how many friend requests will be accepted automatically by each Facebook account.

✅ If You Want to Accept Friend Requests...

Set the Number of requests to accept per account: 10

This means each account will accept up to 10 incoming friend requests during the task run.

✅ Check Accept All

It will accept all pending friend requests up to the specified number, without filtering by gender, mutual friends, or other criteria.

Real-World Example Setup

Scenario: You want 100 Facebook accounts to each accept 10 incoming friend requests.

Go to Select Accounts and choose 100 accounts.

In List of Accepted Friends: add or import accepted friends' usernames

In List of Exlcuded Friends: addor import unaccepted friends' usernames

In Task Settings:

Set Number of request accept per account: 10

Each account will check its pending friend requests and accept up to 10, without skipping or filtering.
