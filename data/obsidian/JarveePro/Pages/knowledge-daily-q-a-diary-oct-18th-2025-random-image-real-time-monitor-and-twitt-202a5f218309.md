2. System Behavior Clarification – Twitter AI Template Availability

“When you select a Twitter post campaign, you cannot use AI templates directly In JarveePro.

Instead, create a

‘Search and Generate’

or

‘Only Generate’

task in

Content Explorer

.”

Explanation:

The

AI Template

feature is only available inside

, not within direct Twitter post campaigns.

This is because

Tweet and Post Campaigns

are designed for

execution

, not for

content generation

Content Explorer is not limited to social media — it monitors all online trends, RSS feeds, Yahoo Finance, StockTwits and Reuters to generate insights and ideas

To generate AI-based tweets:

Go to

Content Explorer → Create Generate Task

Choose either

Search + Generate

(based on trends/RSS) or

Only Generate

(create from scratch).

Attach the generated results to your Twitter campaign for publishing.

Conclusion:

This is not a missing feature or bug. It is a

structural design

to separate AI creation and posting automation.

3. New AI Random Image Posting Feature

User Feedback:

“Can the system make AI posts randomize whether they include a photo or not?

For example, I upload 100 images, but I don’t want every post to use one.”

-Yes choose random and take a look at

this notes

"Yes, i know it can select between the provided images randomly, but what i am suggesting is that it does not use a photo at all sometimes.

Lets say i make a bot so 50 posts, but i only want images on half of them? That is currently not possible.

I guess the only way is to create 2 identical campaigns one with images and one without"

--Then add 25 image only

How to set it up for your example (50 text posts, 25 images):

Create a single campaign.

Upload or paste

50 text items

into

Post Text

Upload

25 images

via

Select Photo/Video

In

Media assignment mode

, choose

Random

(so images are attached randomly to some posts and not others).

Set

Items per Campaign = 50

Times Allowed per Photo/Video = 1

(if you want each image used only once).

Times Allowed per Photo/Video by same Account = 1

and

Max Uses per Target = 1

for strict non-reuse.

Configure

Wait Time (sec)

to control posting cadence.

Preview / run the campaign — the system will pick images randomly for roughly 25 of the 50 posts (depends on randomness and limits).
