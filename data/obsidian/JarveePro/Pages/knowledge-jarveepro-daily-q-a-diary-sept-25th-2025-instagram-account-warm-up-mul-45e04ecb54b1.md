If my account gets banned, should I change my proxy?

Yes. Once an account is banned, you should switch to a

fresh proxy

before adding a new account. Reusing the same proxy may increase the risk of another ban since IP history is often flagged.

How long should I warm up new Instagram accounts before sending mass DMs?

On average,

10–14 days

of warm-up is recommended. Start with light actions (likes, follows, story views) before gradually introducing DMs. Never jump into mass messaging right away.

How do I run tasks with multiple accounts? Currently, only one account finishes.

Go to the

Campaign Manager

and locate the campaign you’re running.

Then:

Check the Accounts Page

– If you only selected

one account

, that’s why only one is running. (Note:

JarveePro Individual version only supports one account

.)

Adjust “Times Allowed per Account”

– If you set it to

1–1

, then each account will only run once. Change it to a wider range, such as

10–20

, so each account can run multiple times within that range.

Consider Upgrading

– If you need to run tasks on multiple accounts at scale, upgrade to the

Business

Enterprise

, or

Full Version

. These plans allow multi-account automation with higher task execution flexibility.

In short: either change your campaign settings to allow more runs per account, or upgrade your plan to handle multiple accounts simultaneously.

If I do a lot of engagement, is 2–3 weeks enough before sending 50 DMs per account?

It depends on the account’s

age, trust score, and warm-up activity

. For new accounts, 2–3 weeks may still be risky for 50 DMs/day. A safer approach is:

Week 3: 10–20 DMs/day

Week 4+: 30–40 DMs/day

Gradually scale to 50 DMs/day only if engagement rates stay healthy and no blocks appear.
