## Content

How to Monitor and View Instagram Reels & Stories with JarveePro Content Explorer

2026-01-29

Introduction:

Keeping your Instagram accounts active with fresh, relevant content is crucial for boosting engagement. Manually tracking Reels and Stories is time-consuming and inefficient, especially when managing multiple accounts. JarveePro’s Content Explorer automates this process, allowing you to monitor specific users’ Reels and Stories the moment they’re posted. In this guide, we’ll walk you through how to set up monitoring tasks, view content campaigns, and take full advantage of JarveePro’s automation features to maximize your reach and visibility.

Step 1: Create a Search Task in Content Explorer

Open

JarveePro Content Explorer

Click

Create Task

Fill in

Task Name

(e.g.,

Instagram_SearchStoryByUsers_JarveeProAdmin

).

Select the

Type

Search

if you only want to track content.

Search + Generate

if you also want to produce content from results.

Under

Search Source

, configure:

Platform

: Instagram

Search Type

Search Story by Users

(or

Search Reels by Users

Run Accounts

: Select the account(s) that will perform the tracking.

Usernames

: Enter the target usernames.

Step 2: Configure Monitoring Settings

Save all results

: Check this to ensure every story/reel is recorded.

Enable real-time monitoring

Option 1:

Search all new results

— captures everything the user posts, for example 100, and then

continue monitoring future uploads.

Option 2:

Search for results published within X hours

— prevents wasting resources on old content.

Example: Scrape the last 24 hours first, then continue monitoring future uploads.

Monitoring interval (minutes)

: Set a range (e.g., 10–15 minutes).

Active monitoring hours

: Define when the task should run (e.g., 00:00–23:59).

Tip: The setup for

Search Story by Users

and

Search Reels by Users

is identical.

Step 3: Use the Monitor Task as Source for Viewing Campaigns

Go to your

View Stories/Reels Campaign

Select

Monitor Task

as the content source.

JarveePro automatically finds the Reels/Stories and executes the views for your account.

This system keeps your accounts active on relevant content continuously — no manual input required.
