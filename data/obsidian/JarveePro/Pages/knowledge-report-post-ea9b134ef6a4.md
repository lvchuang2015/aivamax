Report Post

2025-05-23

Step 1: Choose "Campaigns" and Facebook, and select reporting task.

Step 2: Select account(s) and add multiple post linksyou want toreport. You can import multiple links in CSV format or add them one by one.

Step 3:Complete task settings and click "OK" to start.

What This Page Does:

This section is used to configure how many post reports each Facebook account will make and how the data will be used during the task execution.

If You Want to Simulate Reporting Post to 500 (One Per Account)

Select "Number of posts each account reports":

Set it: From 1 to 1.

Select "Number of report for each post":

Set it: 500 to 500.

In Select Accounts:

Import 500 Facebook accounts.

In Post Source:

Import 500 post URLs to report.

In Account Use Interval(s):

Set it: From 1 to 1 (can adjust to add delays between accounts).

Effect: Each of the 500 accounts will report to 1 video. Total: 500 replies.

If You Want 1 User Get 500 Reports (Using Multiple Accounts)

Set it: From 500 to 500.

Import just 1 post URL to report.

Effect: The same post link will get 500 reports from 500 accounts. Total: 500 replies.

Engagement Settings:

Data is not reused: This option ensures that data is not used multiple times.

Random use of data (Unchecked: Data is used in the order it is provided): Enabling this option will randomize the data usage order for more natural results.
