1. Automated Posting with Unique Images

User Question:

How does it work when I create a “Post” task with a new photo every time? Can the bot automatically pull “new” photos from somewhere to upload?

JarveePro Response:

You can upload multiple photos or videos into one campaign and configure each file to be

used only once

. This ensures that no post is duplicated.

To prevent content from being reused, go to:

Campaigns → Instagram (or any platform) → Select Photo/Video tab

(or other)

In this section, you’ll find the field:

Times Allowed per Photo/Video

Recommended setting:

Set it to

1–1

, which ensures that each photo or video is posted only once and won’t repeat in future tasks.

This feature is ideal for creators who manage multiple campaigns and want every post to stay fresh and unique. It’s especially effective when running mass posting tasks across several accounts.

If you wish to pause and resume tasks later, JarveePro will remember which media files have already been used — making your posting workflow efficient and error-free.

When you stop or pause a campaign before it finishes, JarveePro automatically saves your progress.

Upon restarting, you’ll see a

confirmation window

(as shown below):

You have two choices:

Continue

→ Resume from the last saved point.

(Recommended if you want to pick up exactly where the campaign stopped.)

Restart

→ Begin the entire campaign again.

(Useful if you’ve made content or configuration changes and want a clean restart.)

This feature is especially practical for long-running campaigns or multi-account operations, where unexpected interruptions can occur. JarveePro’s built-in checkpoint system ensures that your automation remains efficient and error-free.

5. Scheduled Task Automation

User Question:

If I schedule a task for a specific time and date, does it start automatically, or do I have to start it manually?

JarveePro Response:

Once scheduled, the task status will appear as

“Waiting.”

At the specified time, JarveePro automatically activates the task — no manual intervention is needed. This allows precise timing for campaigns, especially across multiple time zones.
