## Content

Add Bio Information

2025-05-18

Step 1: Choose "Campaigns" and Facebook, and select task.

Step 2: Select accounts and add bio information you want to share. You can import or add them one by one.

Step 3: Choose whether to check this option based on your situation and the information below.

Data is not reused:

Ensures each bio entry from the file is used only once across all accounts.

Random use of data:

If checked, the bio data will be randomly assigned to accounts.

If unchecked, the data will be used in the order it appears in the file.

Bio information file:

A text file that contains the bio descriptions you want to add to Facebook profiles.

Each line or entry represents one bio that can be used by an account.
