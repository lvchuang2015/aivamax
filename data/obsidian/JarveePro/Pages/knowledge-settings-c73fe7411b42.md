Settings

2025-07-18

Step 1: Open JarveePro→Click Pinterest→ Click Settings.

Yescaptcha APIKey:

Input your API key from Yescaptcha to automatically solve captchas during account actions.

SpinnerChief APIKey:

Enter your SpinnerChief API key to enable automatic content spinning (rewriting text content).

Task threads (number of concurrent runs):

Sets how many automation tasks run at the same time. Example: Set to 1 means only one task will run at a time.

Account threads (Number of accounts running simultaneously):

Controls how many accounts can be active/running at once. Example: 1 = one account is active at a time.

Login error account moved to category:

If selected, accounts that fail to log in will be moved to the selected category for easy management.

When using an account, if the IP is not bound, automatically bind the IP:

When this is checked, the software will auto-bind the current IP to the account if it hasn’t already been bound — helps with avoiding bans.

Recover Data button:

Click to recover previous data in case of crashes or unexpected shutdowns.

Check account failed retry times:

How many times to retry checking a failed account login. 0 = No retry.

Form size:

The size of each browser window when running multiple accounts visually: 500×699

Number per Rows:

How many rows of browser windows to display.
