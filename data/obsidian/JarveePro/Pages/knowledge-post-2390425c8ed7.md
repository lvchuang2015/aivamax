## Content

Post

2025-05-28

Step 1: Choose "Campaigns" and Instagram, and select posting task.

Step 2: Select account(s) and add text content(s). You can import multiple text contents in CVS format. Or you can add text content one by one.

Step 3: Add location(s) when you post the posts. You can choose import locations in CVS format or add location one by one.

Step 4: Select photo(es) or video(es).

Step 5: Complete task settings and click "OK" to start.

What This Page Does:

This section allows you to configure how many Instagram posts are made per user account, and how they are distributed across different accounts.

If You Want to Post the Same Content Multiple Times Using the Same Account, How Do You Set It Up?

Select "Number of post(s) per account":

Set it to 500. This means each account will perform 500 post tasks.

For Individual Version:

If you’re using a single TikTok account:

Set "Number of post(s) per account" from 500 to 500 (this ensures the same content is posted multiple times).

Not recommended for large-scale tasks. For scalability with multiple accounts, consider upgrading to Enterprise or Full Version.

For Full Version Users:

Uncheck "Random use of data" to ensure posts follow a specific order, which is important for structured tasks.

Check "Data is not reused" to prevent data from being reused in consecutive tasks.

If You Want to Post Using Multiple Accounts, How Should You Set It?

Keep "Number of post(s) per account" selected:

Set the range from 500 to 500(this controls the number of posts performed for each individual account).

Make Sure You Have the Following:

500 TikTok video/photo contents to post.

500 text contents and locations.

Check "Random use of data":

Enabling this ensures posts are randomized, avoiding repetitive actions and making the automation look more natural.

Check "Data is not reused" to ensure content is not reused across tasks.

Real-World Example Setup for New Users:

Scenario: Perform video posts for 10 different Instagram users using 10 separate accounts.

In Select Accounts:

Choose 10 Instagram account.

In the Select Video/photo Content Tab:

Select or import 10 video/photo contents you want to post.

In Task Settings:

Select "Number of post(s) per account": From 10 to 10 to ensure each account posts once.

Check "Random use of data" if you want to randomize the order of tasks, making the actions seem more natural and less repetitive.

Check "Data is not reused" to prevent the same content from being reused in multiple posts.
