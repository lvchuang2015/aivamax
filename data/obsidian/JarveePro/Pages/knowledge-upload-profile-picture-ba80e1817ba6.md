## Content

Upload Profile Picture

2025-05-19

Step 1: Choose "Campaigns" and Facebook, and select task.

Step 2: Upload profile picture.

Step 3: Complete task settings and click "OK" to start.

This page is for setting how profile pictures are uploaded for Facebook accounts:

Change all profiles as the same

: All accounts will use the same profile picture.

Change all profiles as different (stop it when not enough profile)

: Each account will use a different picture. If there aren’t enough pictures, the task will stop.
