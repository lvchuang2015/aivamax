Retweet

2025-06-02

Step 1: Choose "Campaigns" and Twitter, and select task.

Step 2: Select account(s) and add tweet source(s). You can import multiple tweet sources you want to retweet the tweets in CVS format. Or add one by one.

Step 3: Import multiple text contents you want to add wen you retweet tweets. Or add text content one by one.

Step 4:Browse photo(es) or video(es) when you retweet tweets.

Step 5:

What This Page Does

This tab allows you to set how many retweets each tweet will receive, or how many tweets each account will retweet. You can also control how the retweet data is used and whether accounts are reused.

If You Want One Tweet to Get 500 Retweets

Select "Number of retweets each tweet increases"

Set it: From 500 to 500

Make sure you have 500 Twitter accounts imported and selected

Check "Data is not reused" to ensure each account only retweets once

Leave "Random use of data" unchecked if you want accounts to retweet in the order they are listed

Do not enable "Quick Retweet" if you want retweets to include all content types (text, photo, video)

If You Want Each Account to Retweet a Different Tweet

Select "Number of tweets each account retweet"

Set it: From 1 to 1

Uncheck "Data is not reused" to allow tweet links to be reused by multiple accounts

Import tweet URLs in the Tweet Source tab

Optional: Check "Quick Retweet" if you only want to boost tweet IDs without loading media

Real-World Example

Goal: Use 500 Twitter accounts to retweet the same tweet

Step 1: In "Select Account", choose 500 Twitter accounts

Step 2: In "Tweet Source", add the tweet link you want to promote

Step 3: In "Task Setting" tab:

Select "Number of retweets each tweet increases": set it from 500 to 500

Check "Data is not reused"

Leave "Random use of data" unchecked

Leave "Quick Retweet" unchecked for full content interaction
