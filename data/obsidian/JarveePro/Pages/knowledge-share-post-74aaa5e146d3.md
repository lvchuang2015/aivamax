Share Post

2025-05-17

Step 1: Choose "Campaigns" and Facebook, and select task.

Step 2: Select accounts and add URL of the post you want to share. You can import or add them one by one.

Step 3: Import your text in CSV format or add them one by one.

Step 4: Complete task settings and click "OK" to start.

What This Page Does:

This tab is to configure how many times a post is shared per account, how many times it is shared per post, and where the post is shared (feed, group, page, etc.).

If you Want Each Account to Share 1 Post, what will you do?

Select “Number Of Shares Per Account”

Set it: 1 to 1

→ Each account will share exactly one post.

In Select Accounts: Choose the number of accounts you want to use

In Share Url tab: Provide the URL of the post to be shared.

Set “Number Of Shares Per Post”

Set it: 500 to 500

→ This means 500 accounts will share the same post.

Explanation of Settings:

Number of Shares Per Account:

How many times each account will share the post.

Example: Set to 1 means each account shares the post once.

Number of Shares Per Post:

How many accounts will share the same post.

Example: Set to 500 means the post will be shared by 500 different accounts.

Account Use Interval(s):

Determines the delay between actions for each account.

Example: Set to 1 to 1 means there is no interval between each account's sharing action.

Share now(public):

If checked, the post will be shared immediately and publicly. If unchecked, the share will be scheduled.

Random use of data:

If checked, the posts to be shared will be selected randomly. If unchecked, posts will be shared in the order they are provided.

Data is not reused:

Ensures that each post or share data is used only once per task.

Share To Feed:

Select this option if you want to share the post on the Facebook feed.

Save to file:

If enabled, the URLs of the shared posts will be saved to a file, allowing you to track the posts that have been shared.

Real-World Example Setup for New Users:

Scenario: Share the same post to 500 accounts

In Select Accounts: Choose 500 Facebook accounts

In Share Url: Provide the URL of the post to be shared

In Task Settings:

Number of Shares Per Account: 1 to 1

Number of Shares Per Post: 500 to 500

Share To Feed: Selected

Data is not reused: Checked

(Optional) Enable Random use of data

(Optional) Enable Save to file to track shared posts
