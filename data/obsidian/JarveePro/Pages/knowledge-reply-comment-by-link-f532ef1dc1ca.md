Reply Comment by Link

2025-05-18

Step 1: Choose "Campaigns" and Facebook, and select posting task.

Step 2: Select accounts and add comment link. You can import multiple comment links in CSV format or add them one by one.

Step 3:

You can import multiple comment texts in CSV format or add them one by one.

Step 4: Complete task settings and click "OK" to start.

What This Page Does:

This tab is to configure how many reply comments are sent per Facebook comment link, from per account, and how the comment data is used.

If you Want to Reply the Same Comment to 500 Posts, what will you do?

Select “Number of Reply Comments”

Set it: From 500 to 500 (Each account will reply 500 times)

If you're using Individual Version, you may only have one Facebook account.

In this case, one account will reply 500 times — be cautious to avoid account limits or bans.

If you're a Full Version User, and you want to distribute replies across accounts:

In Select Accounts: Choose 500 Facebook accounts

In Comment Text tab: Write one reply or use spintax

In Comment Source tab: Provide 500 Facebook comment links

In Task Settings:

Select "Number of Reply Comments"

Set it: From 1 to 1 — each account replies only once

Uncheck "Data is not reused" — because you’re using the same comment for different targets

If you Want to Send Unique Replies to 500 Comments, what will you do?

Keep “Number of Reply Comments” selected

Set it: From 500 to 500

Make sure:

You have 500 different comment texts in the “Comment Text” tab

You have 500 different comment links in the “Comment Source” tab

Keep “Data is not reused” checked — to avoid duplicate replies

Real-World Example Setup for New Users:

Scenario: Send the same reply to 500 Facebook comments using 500 different accounts

In Select Accounts: Choose 500 Facebook accounts

In Comment Text tab: Write 1 reply or use spintax

In Comment Source tab: Add 500 Facebook comment links

In Task Settings:

Select "Number of Reply Comments": From 1 to 1

Keep "Data is not reused" unchecked (since the same reply is reused)

Keep other options unchecked (unless needed)
