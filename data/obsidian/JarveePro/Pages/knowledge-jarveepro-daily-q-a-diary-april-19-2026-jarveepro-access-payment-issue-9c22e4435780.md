Introduction

Following this weekend’s server upgrade, a number of users reached out with similar concerns—mainly around access and payments. If you ran into issues earlier, here’s exactly what happened and what you can do now.

Q1: Why couldn’t I open JarveePro or access the system?

Answer:

During the server upgrade window (Friday–Sunday), parts of the system were temporarily unavailable. This is expected during infrastructure-level updates.

Now that the upgrade is complete,

the platform is fully operational again

You should be able to log in and use JarveePro normally.

If you still can’t access it:

Restart the software

Ensure you're using the latest version

In most cases, access issues should already be resolved.

Q2: Why didn’t the custom payment link work before?

Custom payment links were affected during the upgrade due to backend changes in

payment routing and security layers

The good news:

Everything is now restored and stable.

You can now:

Open JarveePro

Go directly to the

or

Payment

page

Complete your purchase or renewal without issues

We recommend using the in-app payment page for the smoothest experience.

Pricing / Payment

No workarounds needed anymore—the system is back to normal.
