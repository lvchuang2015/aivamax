Post

2025-05-17

Step 1: Choose "Campaigns" and Facebook, and select posting task.

Step 2: Select accounts and add post contents. You can import multiple pieces of content in CSV format or add them one by one.

Step 3: The account username or ID that is automatically @ed when posting.

Step 4: Select photos and videos that you want to post.

Step 5: Complete task settings and click "OK" to start.

What This Page Does:

This tab is to configure how many posts are made per Facebook account, how frequently the posts are scheduled, and whether data is reused or randomized.

If you Want Each Account to Post 500 Posts, what will you do?

Select “Number of post(s) per account”

Set it: 500 to 500

→ Each account will make exactly 500 posts.

In Select Accounts: Choose 500 Facebook accounts

In Post Content tab: Provide the post content (text, media, etc.)

In Task Settings:

Set “Account Use Interval(s)”: From 1 to 1

→ This means no delay between each account's posting action.

Explanation of Settings:

Number of post(s) per account:

Specifies how many posts each account will make.

Example: Set to 500 means each account will post 500 times.

Account Use Interval(s):

Sets the delay between actions for each account.

Example: Set to 1 to 1 means no delay between each account's posting action.

Post Story:

If checked, the post will be shared as a Facebook Story.

Post Public:

If checked, the post will be made public immediately.

Data is not reused:

Ensures that the post content is not reused across different accounts.

If unchecked, data could be reused in different accounts.

Random use of data:

If enabled, posts are shared randomly from the provided content. If unchecked, the posts will be used in the order they are provided.

Save post URL to file:

If enabled, the URLs of the posted content will be saved to a file for tracking purposes.

Real-World Example Setup for New Users:

Scenario: You want 500 accounts to each make 500 posts

In Select Accounts: Choose 500 Facebook accounts

In Post Content: Provide 500 different pieces of content (text, media)

In Task Settings:

Number of post(s) per account: 500–500

Account Use Interval(s): 1–1

Post Public: Checked

Data is not reused: Checked

Random use of data: Optional

(Optional) Enable Save post URL to file to track URLs of the posts
