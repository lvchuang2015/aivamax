## Content

Change Profile Name

2025-06-04

Step 1: Choose "Campaigns" and Twitter, and select task.

Step 2: Select account(s) and add name content(s). You can import multiple name contents you want to change in CVS format. Or add one by one.

Step 3:

"Random use of data" and "Data is not reused" are optional tasks. But you must click "OK" to start.

Data is not reused:

When checked, the system ensures that data (such as comment content, post links, etc.) is unique for each operation and not reused.

Random use of data:

When checked, the system will randomly select data for each operation instead of using it in order, reducing the risk of repetitive actions.
