Introduction

Managing JarveePro campaign settings, AI Monitor, and automation features can be confusing for new users. This guide addresses frequently asked questions related to campaign timing behavior, AI Monitor activation, Workflow D setup, and Auto-Like configuration.

Each answer includes direct references to relevant knowledge base articles for deeper clarification.

Q1: What does the “Interval between uses” setting mean in Campaigns when running accounts in Sequential mode?

Answer:

The

Interval between uses

setting defines the waiting time

before the same account runs again in the next loop

It

does not

create a delay between different accounts in Sequential mode. Once one account finishes, the next account will start immediately if available.

Q2: How do I activate my AI Monitor add-on? Do I need a new license key or restart the tool?

Your

existing license key is automatically updated

to include the AI Monitor add-on.

To activate and access the new features:

Restart JarveePro after the license update is applied

No new license key is issued.

Q4: How do I set up Auto-Like (Panel-style) functionality in JarveePro?

To achieve Auto-Like behavior similar to SMM panels, use a Monitor + Action architecture:

Create a Monitor (Watcher)

in Content Explorer

Track posts by specific users

Enable real-time monitoring with a short interval

Create an Action (Executor) Campaign

in Campaign Manager

Use the

Like Post

action

Select the

Post URLs

tab

Link it to the Monitor task

When both tasks are running, JarveePro will automatically detect new posts and trigger likes.
