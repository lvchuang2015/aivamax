1. Handling Google Captcha: Add Your YesCaptcha Key

User (W):

Some of my Facebook accounts failed because of “Verify you are a human.”

Magnet Traffic:

Did you add your YesCaptcha key?

W:

What is that?

It’s an automatic Captcha-solving service that helps bypass Google Captcha verification.

You can follow this setup guide:

JarveePro Settings Overview – YesCaptcha Integration

Explanation:

If you’re running multiple accounts and notice some fail because of a

Captcha challenge

or

“Verify you are a human”

prompt, you need to enable

YesCaptcha

to automate the solving process. Without it, login or posting tasks may pause or fail.

Steps:

Go to

Settings → API Key Settings.

Add your

YesCaptcha API Key.

Save and restart the tasks.

Once active, JarveePro automatically solves

Google Captchas

and other verification prompts in the background — no manual clicking required.

4. New Feature: Retry Failed Accounts

User:

All good, it’s just about the status — how can I track which accounts failed, so I can rerun them?

Answer:

That’s where JarveePro’s new feature —

Retry Failed Accounts

— comes in.

helps you save time and avoid restarting an entire campaign when only a few accounts failed.

You now have

three options

under the

Copy Options

menu:

Option

Description

When to Use

1. Duplicate Full Campaign

Creates an exact copy of your campaign, including successful and failed accounts.

When you want to restart the entire campaign.

2. Copy Campaign Settings Only

Makes a new campaign using the same targets, filters, and settings but no history.

When you want a clean start.

3. Duplicate & Retry Failed Accounts

Continues from where it stopped. Retries only failed accounts while skipping those that already succeeded.

When you want to save time and continue efficiently.

How It Works:

JarveePro identifies which accounts failed due to errors, timeouts, or Captcha interruptions.

It automatically re-queues those failed accounts.

Successful accounts are skipped to prevent redundant actions.

This feature is a

major time-saver

, letting you fix failed runs in seconds instead of starting everything over.
