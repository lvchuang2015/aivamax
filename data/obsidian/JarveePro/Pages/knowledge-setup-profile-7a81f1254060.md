Setup Profile

2025-06-03

Step 1: Choose "Campaigns" and Twitter, and select task.

Step 2: Select account(s) and add bio content(s). You can import multiple bio contents you want to setup in CVS format. Or add one by one.

Step 3: Import multiple location contents (city, country, place name...) in CVS format. Or add one by one.

Step 4: Upload cover photo(es) source and profile photo(es)

Step 5: Choose one of tasks and complete task settings according to your needs. Then, click "OK" to start.

Change all info as the same

: All accounts will have the same profile info.

Change all info as different

: Each account will have different profile info, and the task stops if there’s not enough unique info.
