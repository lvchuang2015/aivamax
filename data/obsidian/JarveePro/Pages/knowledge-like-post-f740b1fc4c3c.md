Like Post

2025-05-28

Step 1: Choose "Campaigns" and Instagram, and select task.

Step 2: Select account(s) and add post content(s). You can import multiple post sources in CVS format. Or you can add post source one by one.

Step 3: Complete task settings and click "OK" to start.

What This Page Does:

This tab is to configure how many Instagram posts each account likes, and how many likes each post receives.

If You Want to Get 500 Likes on One Post:

Select “Number of Likes Each Post Increases”

Set it: From 500 to 500 — this means the selected post will receive exactly 500 likes from different accounts.

✅ This option is selected in the current setup.

Set “Account Use Interval(s)”

Set it: From 1 to 1 — this ensures that each account likes a post with a 1-second delay in between actions, helping mimic human activity.

✅ Interval is active.

Check “Random Use of Data”

This means the post links in your list will be liked in random order by the accounts.

✅ Randomization is enabled for more natural behavior.

If You Want Each Account to Like a Different Post:

Select “Number of Posts Each Account Likes”

Set it: From 1 to 1 — this ensures that each account only likes one post.

✅ This option is currently enabled.

Enable Random Use of Data

This helps spread likes across your post list unpredictably, simulating organic engagement.

Adjust Account Use Interval(s) as needed to manage pacing and platform limits.

Real-World Example Setup for New Users:

Scenario: 500 Likes on One Post

In Select Accounts Tab: Choose 500 Instagram accounts

In Post Links Tab: Add the URL of the post you want to promote

In Task Settings:

Select “Number of Likes Each Post Increases”: From 500 to 500

Select “Number of Posts Each Account Likes”: From 1 to 1

Set Account Use Interval(s): From 1 to 1

Check “Random Use of Data”

✅ This setup ensures the post gets 500 likes from different accounts, with randomized order and controlled timing to appear natural.
