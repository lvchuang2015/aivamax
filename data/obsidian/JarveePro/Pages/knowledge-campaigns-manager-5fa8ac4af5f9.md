Campaigns Manager

2025-05-12

Campaigns Manager: Setup and management of bulk content publishing.

Campaigns Search:

Used to search for already created campaigns (enter keywords to quickly locate).

New:

Create a new campaign.

Delete:

Delete the selected campaign.

Start:

Start the selected campaign and let the system start automatically publishing content.

Stop:

Stop the currently running campaign.

Reset:

Reset the status of the selected campaign, usually used to restart.

Schedule:

Set the schedule of the campaign and arrange the specific publishing time.

Create Campaign:

Set up automated tasks, such as posting, liking, commenting, etc.
