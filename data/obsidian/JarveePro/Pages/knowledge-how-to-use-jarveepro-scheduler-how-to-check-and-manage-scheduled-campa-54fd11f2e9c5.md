How to Use JarveePro Scheduler & How to Check and Manage Scheduled Campaigns

2026-02-13

Introduction

JarveePro Scheduler is designed to control when campaigns run without manually starting them every time.

Instead of launching tasks immediately, you can:

Schedule campaigns to run once

Set specific start times

Monitor upcoming executions

Track remaining time before execution

This guide explains:

How to create a scheduled campaign

How to check if it is valid

Where to monitor countdown time

How to manage or edit scheduled tasks

Part 1 – How to Use JarveePro Scheduler

Step 1: Select Your Campaign

Go to

Campaigns

Select the campaign you want to schedule

Click

Add Schedule

This opens the

Task Schedule window

Step 2: Configure Schedule Settings

Inside the Schedule window:

Platform

→ Auto-selected based on campaign

Campaign Type

→ Example: Post, Reply, Like, etc.

Campaign

→ Selected campaign name

Schedule Type

→ Choose

Run Once

(most common)

Optional settings:

Restart campaign from beginning

Stop after X times

Then set:

Start Time

→ Choose exact date and time

Finally:

✔ Enable Schedule

✔ Click OK

Your campaign is now scheduled.

Part 2 – Understanding Default Schedule Timing

The

default system interval is 40 minutes

This means:

Scheduler checks every 40 minutes

Scheduled tasks are processed based on this interval

Execution time may display slightly differently depending on system cycle

This is normal behavior.

Part 3 – How to Check Scheduled Campaigns

Method 1: JarveePro Scheduler Manager

Click

JarveePro Scheduler

Open

Scheduler Manager

You will see:

Platform

Campaign Type

Schedule Type

Status

Start Time

Remaining Number

Status Explanation:

Valid

→ Schedule is active and ready

Invalid

→ Schedule is not active or expired

If your campaign shows

, it is correctly scheduled.

Method 2: Campaign Dashboard Countdown

In the main Campaign Dashboard:

Scheduled campaigns will display:

Scheduled (In 60m)

→ Running in 60 minutes

If time exceeds →

Scheduled (Over 60m)

This countdown shows how long until execution.

Important:

This does NOT mean something is wrong.

It reflects:

The scheduled start time

The scheduler processing interval

Part 4 – How to Manage or Edit Scheduled Campaigns

Inside Scheduler Manager, you can:

Edit schedule (blue icon)

Delete schedule (red icon)

Check remaining number

Verify start time

Confirm validity

If you want to change the time:

Edit schedule

Update Start Time

Save

Ensure it still shows

Valid

Common Questions

Why does it say “In 60m” instead of exact minutes?

Because:

The scheduler works in cycles

Countdown display rounds based on system timing

This is normal and expected.

What If My Schedule Does Not Run?

Check:

Is status showing

Is Enable Schedule checked?

Is VPS Mode active (if using VPS)?

Is the campaign itself enabled?

Is system time correct?

In 95% of cases, “Valid” status means everything is configured correctly.

Summary

JarveePro Scheduler allows precise control over campaign execution.

Key points:

Default schedule interval: 40 minutes

Check scheduled tasks in Scheduler Manager

“Valid” means correctly configured

Countdown shows expected execution time

“Over 60m” is normal if between cycles

Understanding how scheduler cycles work prevents confusion and unnecessary troubleshooting.

Automation is not just about starting tasks — it’s about controlling when and how they run.
