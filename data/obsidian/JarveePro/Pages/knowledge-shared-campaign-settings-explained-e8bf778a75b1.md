Shared Campaign Settings Explained

2025-10-22

Most JarveePro campaign modules share the same structure — whether you’re posting, replying, or commenting.

Each campaign includes several tabs such as

URL

Text

Photo

, and

Video

, where you can define your content and control how it’s used.

Although each campaign type (Post, Comment, Reply) serves a different purpose, their internal settings follow a shared logic.

This guide explains each parameter so you can understand how JarveePro decides when and how to use your photos, videos, and text — ensuring your AI automation feels natural, human, and varied.

In this guide, we will walk you through the common settings for

JarveePro Campaigns

that involve

URLs

text

photos

videos

comments

. These settings are frequently used across different campaigns like

Facebook Comments

Instagram Posts

, and

Twitter Replies

. Understanding these settings will help you streamline your campaign setup and optimize your social media automation process.

1. Accounts Tab

The

Accounts

tab in JarveePro allows you to select the accounts you wish to use in your campaign. It is important to configure this section properly as it ensures that the right profiles are being used for the tasks at hand.

Account Selection

: Select accounts manually or automatically by checking the box next to each profile.

Categories

: Use account categories (e.g., "Twitter", "Facebook") to group and manage accounts more efficiently.

Campaign Mode

: Choose whether you want to use as many accounts as possible or as few as possible, depending on the needs of your campaign.

2. URL Tab (Post & Comment URLs)

This tab is essential for campaigns that involve engaging with specific content, like posting comments on URLs or replying to comments.

Post URLs

: Add direct links to the Facebook or Instagram posts you wish to comment on or interact with. You can manually input the URLs or import them via a

CSV

or

Excel

file.

Comment URLs

: Use this for campaigns that involve replying to specific comments on posts. Just like with post URLs, you can add the comment URLs manually or import them.

Example Use Cases:

Commenting on a Facebook post using its direct URL.

Replying to a specific comment on a social media post.

3. Text Tab (Comment Text & Auto AI-Generated Comments)

The

Text

tab allows you to specify what content will be used for comments. This is where you can define the message you want to post on social media.

Manual Text Import

: Manually upload or input comments using

CSV

or

Excel

files.

Auto-AI Comments

: If enabled, JarveePro can automatically generate comments based on the content of the post or the context of the campaign, saving you time and ensuring relevance.

Sequential or Random

: You can choose whether comments will be posted in a

sequential

random

order. The

option is great for reducing the risk of appearing too automated.

4. Photo/Video Tab

If your campaign includes media (images or videos), this tab allows you to select the media files you wish to use.

Select Media

: Choose between photos or videos that will be added to the campaign posts or comments.

Photo/Video Settings

: Each campaign can include multiple images or video clips to add visual variety.

You can choose whether to use them

Sequentially

(in order) or

Randomly

, and control how often each is used.

Setting Name

Optimized Description

Example Use Case

Sequential / Random

Choose how JarveePro selects photos or videos.

Sequential

: Uses files in order (e.g., image 1 → 2 → 3).

Random

: Selects media randomly for more variation.

Random is ideal for AI Monitor or Comment campaigns where natural diversity matters.

Wait Time (sec)

Time interval between each media use. Define minimum and maximum seconds to simulate human-like pauses.

Example: 5–15 seconds = more realistic posting speed.

Times Allowed per Photo/Video

How many times each photo or video can be reused before JarveePro stops using it.

Example: Set to “1” if you never want the same image to appear twice.

Times Allowed per Photo/Video Per Account

Limits how often the same account can reuse a specific media file.

Prevents repetitive visual content from a single account.

Photo/Video Allowed per Comment

Defines how many photos or videos can be included per comment or reply.

Example: 1 = one image per comment; 0 = text only.

Chance to Include Photo (%)

(new)

Set probability that a photo will be included in a reply or post.

Example: 40% = roughly 4 out of 10 comments will include a random image.

Chance to Include Video (%)

Set probability that a video will be included in a reply or post.

Example: 20% = roughly 1 out of 5 posts will include a video.

Example Use Case:

Posting an image with a comment on Instagram to boost engagement.

Uploading a promotional video to a Facebook page.

Best Practice Tips

Keep media variation high for natural AI engagement. Upload at least

20–50 images

and

5–10 short videos

per campaign.

Use

Random Mode

whenever possible to avoid repetitive posting patterns.

Combine

Spintax + Hashtag Randomizer + Media Probability

for realistic and safe automation.

Wait Time (sec)

to mimic human reaction intervals — 3–15 seconds for comments, 10–30 seconds for replies.

Chance to Include Photo/Video (%)

for dynamic variance.
