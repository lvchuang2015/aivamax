## Content

Follow his followings & followers

2025-06-01

Step 1: Choose "Campaigns" and Instagram, and select task.

Step 2: Select account(s) and add user source(s). You can add multiple user sources of someone's followings. Or add one by one.

Step 3: Complete task settings and click "OK" to start.

Number Of Profile To Follow Per Account

Value:

5 to 5

Meaning:

Each Instagram account you run this task on will use

exactly 5 target profile URLs

. These are the

source profiles

whose

followings

you want to follow.

Example:

If you input 10 Instagram profile URLs, the task will randomly select

of them per account (unless “random use of data” is checked, then it's in order).

Number Of Followings to Follow

Value:

20 to 20

Meaning:

From each target profile (from the 5 used per account), the software will follow

20 users

from their

following list

Total Follows per account per run = 5 profiles × 20 = 100 follows

Number Of Follow(s) Per Profile

1 to 1

This setting is ignored

when "Number Of Followings to Follow" is active. No effect in this configuration.

Account Use Interval(s)

Value:

This is the

pause interval (in minutes)

between two accounts doing this task.

Each account will wait

1 second

after the previous before starting the task.

Optional Settings:

Random use of data

– if unchecked, the tool uses data

in order

Save follow records to file

– if checked, it logs all follow actions to a file.

Workflow Summary:

For

each account

, JarveePro2 will:

Use

5 Instagram profile URLs

Go to each profile’s

following list

Follow 20 users

from each profile's following list (total =

100 follows/account/task run

).

Wait

1 second

before the next account starts the task.
