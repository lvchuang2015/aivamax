Share Post

2025-05-28

Step 1: Choose "Campaigns" and Instagram, and select task.

Step 2: Select account(s) and add post content(s). You can import multiple post links you want to share to others in CVS format. Or you can add post link one by one.

Step 3: Import multiple text content you want to share with others in CVS format or add content one by one.

Step 4: Import multiple usernames of people you want to share posts with in CVS format. Or add username one by one.

Step 5: Complete task settings and click "OK" to start.

What This Page Does:

This tab is to configure how many Instagram comments each account replies to by link, and how many reply comments each target comment receives.

If You Want to Send 500 Replies to One Comment:

Select “Number of Reply Comments Per Post”

Set it: From 500 to 500 — this means the selected comment link will receive exactly 500 replies from your selected accounts.

✅ This setting is currently enabled.

Uncheck “Random Use of Data”

This ensures that the accounts will reply to the comment links in the exact order they are provided.

❌ Random mode is not enabled.

Set “Account Use Interval(s)”

Set it: From 1 to 1 — this means each account action is spaced by 1 second for more human-like behavior.

✅ Interval is enabled.

If You Want Each Account to Reply to Different Comments:

Select “Number of Post Reply Comments Per Account”

Set it: From 1 to 1 — this ensures each account only replies once to one post/comment.

Not selected in current setup.

This will maintain the consistency of reply order based on the comment list you upload.

Set Account Interval as needed to manage execution timing.

Real-World Example Setup for New Users:

Scenario: 500 Replies to One Comment

In Select Account Tab: Choose 500 Instagram accounts.

In Comment Links Tab: Paste the comment/post link you want to target.

In Task Settings:

Select “Number of Reply Comments Per Post”: From 500 to 500

Leave “Number of Post Reply Comments Per Account” unchecked

Set Account Use Interval(s): From 1 to 1

Uncheck “Random Use of Data”

✅ This configuration ensures one comment gets 500 unique replies from 500 accounts, with consistent timing and order.
