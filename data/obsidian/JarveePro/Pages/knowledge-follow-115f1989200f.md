Follow

2025-06-14

Step 1: Choose "Campaigns" and TikTok, and select task.

Step 2: Select account(s) and add user source(s). You can import multiple user sources you want to follow in CVS format. Or you can add text content one by one.

Step 3:

Choose one of tasks and complete task settings. Then complete account use intervals if you select multiple accounts before. Last, click "OK" to start.

What This Page Does:

This tab is to configure how many profiles are followed per TikTok account, and how many times each profile is followed.

If You Want to Follow the Same 500 Profiles with 500 Accounts, What Will You Do?

Select “Number of Profiles To Follow Per Account”

If you're using an individual version, you only have the option of using one TikTok account.

Keep “Number of Follows Per Profile” selected

Set it: From 500 to 500 (This means each profile can be followed by up to 500 accounts. If you want a larger scale of follow actions, you would need to upgrade to the Enterprise Version or Full Version to manage more accounts).

If you're a full version user,

Set it: From 1 to 1 (or more if needed). This ensures each account follows only one profile at a time.

Uncheck “Random use of data” (optional depending on your strategy). If unchecked, data will be used in the order it is provided.

If You Want to Follow Unique Profiles with 500 Accounts, What Will You Do?

Keep “Number of Follows Per Profile” selected.

Set it: From 500 to 500 (each account will follow a different profile).

Make sure:

You have 500 profiles (usernames or URLs).

You have 500 TikTok account entries ready for use.

Real-World Example Setup for New Users:

Scenario: Follow 500 different profiles with 500 different TikTok accounts.

In Select Accounts: Select 500 TikTok accounts.

In User Source: Import 500 unique profiles (usernames or URLs).

In Task Settings:

Use “Number of Profiles To Follow Per Account”: From 1 to 1 to ensure each account only follows one profile.

“Number of Follows Per Profile”: From 1 to 1 to ensure each profile is only followed once.

Uncheck “Random use of data” (if you want the accounts to follow profiles in order).
