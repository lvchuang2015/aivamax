Monitoring

2025-07-18

Step 1: Open JarveePro→Click “Pinterest”→Choose “Monitoring”

Step 2: Select account→Set interval after last run→Set account interval time→Choose filter type→Add keyword to search→Set up time you want to monitor→Click "Start".

Set interval after last run:

This means how often the same task runs again for the same page. Example: 1 hour means it will recheck the target every hour.

Account Interval Time:

Delay between each account executing the monitoring task. Example: If monitoring with multiple accounts, they’ll wait 5 seconds apart.
