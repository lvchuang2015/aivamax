## Content

Like Videos/Shorts

2025-06-04

Step 1: Choose "Campaigns" and YouTube, and select task.

Step 2: Select account(s) and add video source(s). You can import multiple video sources you want to watch in CVS format or add them one by one.

Step 3:

What This Page Does:

This tab is to configure how many YouTube videos each account will like and how many likes each video will receive.

If you Want to Like 500 Videos:

Select “Number of Videos Each Account Likes”

Set it: From 1 to 1 (or more if you want to like multiple videos per account).

Select “Number of Likes Each Video Increases”

Set it: From 500 to 500 (This ensures each video gets 500 new likes from the selected accounts).

If you Want Each Video to Gain Unique Likes:

Set it: From 1 to 1 to ensure each account likes only one video.

Set it: From 500 to 500 to ensure each video gets 500 likes.

Uncheck “Random use of data”

This ensures that the accounts will like videos in the exact order they are provided.

Real-World Example Setup for New Users:

Scenario: Liking 500 Videos

In Select Accounts: Select 500 YouTube accounts.

In Video Source: Choose the videos you want to like.

In Task Settings:

“Number of Videos Each Account Likes”: Set it to 1 to ensure each account likes only one video.

“Number of Likes Each Video Increases”: Set it to 500 to add 500 likes to each video.

Uncheck “Random use of data” to maintain the order of video likes.

This ensures that each account will like one video, adding 500 likes to each video.
