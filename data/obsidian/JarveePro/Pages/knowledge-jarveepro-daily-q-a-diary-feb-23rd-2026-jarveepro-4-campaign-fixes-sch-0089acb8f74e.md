Q1: I want to upload exactly 1 Instagram post per day for 7 days, but when I manually start the campaign, it always posts the first item again instead of continuing the sequence.

Answer:

This behavior occurs because manually starting the campaign resets the execution sequence.

To maintain correct posting order, you must use the JarveePro Scheduler instead of manual start.

Correct setup:

Add all posts to the campaign list

Enable Scheduler

Set campaign to run once per day

Allow Scheduler to control execution automatically

The Scheduler preserves sequence memory and ensures each post is published in proper order.

Manual start should only be used for testing, not sequential publishing campaigns.

Q2: The Scheduler is not starting the campaign at the scheduled time, and the Remaining Number suddenly drops to 0.

This issue is usually caused by incorrect Scheduler configuration.

Please verify the following settings:

Scheduler is enabled

Correct time and timezone are set

Campaign has remaining executions available

Campaign is not already marked as completed

JarveePro application is running during scheduled time

Also avoid manually starting the campaign when Scheduler is enabled, as manual execution can interrupt scheduled sequences.

Proper Scheduler configuration ensures fully automated daily posting.

Q3: Only one account runs at a time, but I want multiple accounts to run the same campaign simultaneously.

Answer:

This is controlled by JarveePro thread settings.

To allow multiple accounts to run simultaneously:

Go to Settings

Locate Thread Settings

Increase the number of concurrent threads

Thread settings determine how many accounts can execute automation tasks at the same time.

Higher thread settings allow faster execution but should be balanced based on your system performance.

Refer to the JarveePro knowledge base guide on Shared Campaign Settings for full instructions.
