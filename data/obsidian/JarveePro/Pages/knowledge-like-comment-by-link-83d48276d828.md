Like Comment by Link

2025-06-01

Step 1: Choose "Campaigns" and Instagram, and select task.

Step 2:Select account(s) and add comment link(s). You can import multiple comment links you want to like in CVS format. Or you can add link one by one.

Step 3: Complete task settings and click "OK" to start.

What This Page Does:

This tab is used to configure how many Instagram accounts will like specific comments, or how many comments each account will like, based on the links you provide.

Task Execution Flow:

Number of Likes Each Comment Increases

Set to: 500 – 500

Each comment in your data list will receive exactly 500 likes from different accounts.

✅ This option is selected in the current setup.

Account Use Interval(s)

Set to: 1 – 1

This sets the interval (in seconds) between each time an account is used for liking. A delay of 1 second helps slow down actions for safety.

❌ Currently disabled.

Random Use of Data

Unchecked

The tool will process the comment links in the exact order they appear in your input list. This ensures consistency and control.

❌ Not randomized.

Number of Comments Each Account Likes

If this option is selected instead, each Instagram account will like only 1 comment from your list.

🔲 Not selected in current setup.

Example Use Case:

You want to make 500 Instagram accounts like the same comment to boost its visibility.

Upload your comment links.

Select "Numbers of likes each comment increases", set to 500–500.

Leave "Random Use of Data" unchecked to go in order.

(Optional) Set a delay using “Account Use Interval(s)” if needed.
