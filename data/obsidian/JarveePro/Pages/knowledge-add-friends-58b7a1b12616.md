Add Friends

2025-05-19

Step 2: Select account(s) and add user link sources. You can import multiple link sources in CSV format or add them one by one.

Step 3: Complete task settings and click "OK" to start.

What This Page Does:

This tab is to configure how many users are added as friends per Facebook account, how many accounts add the same user, and how the user data is handled.

If you Want to Add 500 Users Using One Account, what will you do?

Select “Number Of User Added Per Account”

Set it: From 500 to 500

→ One account will send friend requests to 500 users

Set “Number Of Added Per User”: From 1 to 1

→ Each user receives only one friend request

In Select Account: Choose one Facebook account

In User Source tab: Provide 500 Facebook user profile URLs

Keep “Data is not reused” checked to avoid repeated requests to the same user

If you Want 500 Accounts to Add the Same User, what will you do?

Select “Number Of Added Per User”

→ The same user will be added by 500 different accounts

Set “Number Of User Added Per Account”: From 1 to 1

→ Each account sends one friend request

In Select Account: Choose 500 Facebook accounts

In User Source tab: Provide a single user profile link (or repeat the same one)

Keep “Data is not reused” unchecked if you want to allow multiple accounts to add the same user

Make Sure:

Random use of data: Enable this if you want accounts to add users in random order.

If unchecked, users will be added in the sequence they are listed.

Account Use Interval(s): Optional. Set a delay range between actions (e.g., 1–1 = no delay).

Data is not reused: Checked by default. Each user will only be added once per account.

Real-World Example Setup for New Users:

Scenario: You want 500 Facebook accounts to each add a different user

In Select Accounts: Choose 500 Facebook accounts

In User Source: Provide 500 unique Facebook user URLs

In Task Settings:

Select “Number Of User Added Per Account”: 1–1

Select “Number Of Added Per User”: 500–500

Keep “Data is not reused” checked

(Optional) Enable “Random use of data”

(Optional) Set Account Use Interval(s) if needed
