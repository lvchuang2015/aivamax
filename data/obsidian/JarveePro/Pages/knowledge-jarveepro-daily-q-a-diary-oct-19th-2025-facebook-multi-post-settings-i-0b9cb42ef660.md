Case 1: Facebook Multiple Post & Like Task Issue

User Feedback:

“I can’t make multiple posts with a lot of accounts selected — it only makes one post with one account.”

Investigation:

The user experienced difficulty in posting simultaneously across multiple Facebook accounts. Upon checking, all accounts were connected successfully, but the settings for post distribution and engagement control required fine-tuning.

Resolution Steps:

Shared detailed guides for campaign configuration:

JarveePro Full Version FAQ

Guided the user to review and adjust key automation parameters:

Posts per account

– defining how many posts one account performs.

Posts per Text

– controlling how many post each text can be performed from multiple accounts.

Posts Per Text Per Account– controlling how many post each text can be performed from each account.

Provided visual references with screenshots for both the “Account Behavior” and “Task Settings” tabs to ensure proper configuration.

Confirmed that operation resumed after settings were corrected.
