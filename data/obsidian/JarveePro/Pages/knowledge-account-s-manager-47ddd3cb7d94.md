## Content

Account(s) Manager

2025-05-07

Click accounts on the left, you can add accounts one by one or import multiple accounts at once. Then start your multi-accounts at once.

If needed, set up proxy or VPS after adding account.

1. Left Sidebar -- Platform Navigation

Accounts

-- The current tab, used for adding, editing, and managing all your social media accounts.

2. Middle Left Panel--

Account Categories

Category

--Organize accounts into different categories.

Add--

Modify the category name(date or anything you like) and platforms. For example: 2025/5/7. Enter “57” as the category name.

Delete--

Remove the entire category.

3. Top Center--

Account Management Toolbar

Import

– Bulk-import accounts from a file

Export

– Export account info to a file

Add

– Add a new account manually

Delete

– Delete selected accounts

Start / Stop

– Start or stop automation tasks for selected accounts

Proxy

– Set proxies to keep accounts safe

VPS

– Assign VPS servers for distributed task execution

More

– Additional tools and settings

4. Right Section--Account Management Toolbar

Account

– Username or ID

Status

– Running, failed, or locked

Category

– Platforms

Proxy/VPS

–Whether it is used

Information

– Number of friends

Message

– Alerts or actions needed
