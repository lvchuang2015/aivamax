JarveePro Third-Party Services Settings

2025-12-15

Complete Guide to API Keys, Thread Settings, Browser Settings, Data Backup & Rate Limits

JarveePro integrates with multiple

third-party services

to improve account verification, automation stability, and overall safety. Correct configuration of these settings is essential to avoid errors, failed tasks, and unnecessary account risks.

This article explains

each setting in detail

, why it matters, and how to configure it properly.

1️⃣

API Key Settings

Connect External Services to JarveePro

JarveePro relies on external API services to handle captchas, phone verification, and AI-based features. These services require valid API keys.

YesCaptcha API Key

Captcha Solving Service

Website:

YesCaptcha

Used for: Account verification, login protection, captcha challenges

How to get the API key

Create an account on YesCaptcha

Top up a small balance

Copy the API key from your dashboard

Paste it into

JarveePro → Settings → Third-Party Services

SadCaptcha API Key

Primarily Used for TikTok Automation

SadCaptcha is mainly used in JarveePro for handling

TikTok-related captcha challenges

, especially during login, verification, and automation processes.

When SadCaptcha is needed

TikTok account login verification

Captcha challenges during TikTok automation

Increased stability for TikTok-related actions

Setup steps

Create an account at

SadCaptcha

Add a small balance

Copy your

SadCaptcha API Key

Paste it into

JarveePro → Settings → Third-Party Services

Save your settings

OpenAI API Key

AI-Powered Features

Used for:

AI content generation

Smart replies

Text optimization features (where available)

Setup

Obtain your OpenAI API key

Paste it into the OpenAI API Key field

Save settings

DaisySMS API Key

Used for YouTube Phone Verification (When Required)

DaisySMS is used in JarveePro

only when YouTube requests phone number verification

, such as during account creation, login recovery, or security checks.

When DaisySMS is used

YouTube phone number verification prompts

Account recovery or security confirmation

SMS-based verification requests from YouTube

Setup steps

Register at

DaisySMS

Top up your balance

Copy your

DaisySMS API Key

Paste it into

JarveePro → Settings → Third-Party Services

Save

Tips

You don’t need every third-party service enabled at once.

Enable

SadCaptcha

for TikTok accounts

only if YouTube asks for phone verification

This keeps your setup

clean, efficient, and cost-effective

API Service Status

Enable Internal API Communication

This setting controls whether JarveePro’s internal API service is running.

Options

Stopped

– API service is disabled

Start the API service when the software starts

– Recommended

Always enable

Start API service automatically

to ensure:

Third-party services function correctly

AI features work without interruption

External requests are handled properly

API Server Start Port

Default Port:

6471

This is the local port JarveePro uses to run its API service.

Recommendations

Leave at

unless another application uses the same port or your IT team requests a custom port

2️⃣Browser Settings

Simulate Real User Behavior

Browser settings help JarveePro behave more like a real user session.

Key benefits:

Reduced detection risk

Better session stability

More natural login behavior

Best practice

Do not frequently change browser profiles

Use consistent environments per account

Avoid mixing accounts across browsers

3️⃣Data Backup

Protect Your Configuration

JarveePro allows you to back up:

Accounts

Automation Tasks

Why this matters

Prevents data loss after crashes or updates

Makes migration to new machines easier

Saves hours of reconfiguration

4️⃣ Thread Settings

Control How Fast JarveePro Works

Thread Settings

define how many actions JarveePro can run at the same time.

What this means

Higher threads = faster execution

Lower threads = safer, more stable automation

Best practice

Start with

low to medium thread values

Increase gradually only after confirming account stability

Never max out threads on new or unaged accounts

5️⃣ Rate Limit Settings

The Most Important Safety Feature

Rate limits define

how many actions

an account can perform within a specific time frame, including:

Posts per day

Likes

Follows

Auto replies

Messages

Why rate limits matter

Prevent bans and soft bans

Mimic real human behavior

Extend account lifespan

Recommended approach

Use

conservative limits

, especially for new accounts

Increase slowly over time

Never copy limits from another account blindly

Summary

JarveePro’s Third-Party Services allow marketers to safely and efficiently automate their social media accounts. By properly configuring

API keys

(YesCaptcha for general captcha, SadCaptcha for TikTok, DaisySMS for YouTube verification, OpenAI for AI features) and enabling the

API Service

for SMM panel integration, users can ensure smooth operation across multiple platforms. Additional settings like

thread control, browser profiles, data backup, and rate limits

further protect accounts and optimize automation. Following these guidelines helps prevent bans, maintain account stability, and streamline multi-platform campaigns.
